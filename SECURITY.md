# Security

If you find a security problem, please do not open a public issue with exploit details.

## What to include

- A short description of the issue
- Steps to reproduce it
- The likely impact
- Any logs or screenshots that help

## Response goals

- We will try to confirm the report quickly
- We will work on a fix before asking for public disclosure
- We may ask for more detail if we cannot reproduce the issue

## Secrets

This project uses API keys and tokens. Please keep these out of commits, screenshots, and bug reports.
